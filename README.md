# Автоматизация UI-тестирования сервиса «Яндекс Самокат» (Sprint 5)

Учебный проект по автоматизации сценариев заказа самоката и проверки элементов интерфейса с использованием Selenium WebDriver.

## 🛠 Технологии и инструменты
* **Язык:** Python 3.x
* **Тест-фреймворк:** Pytest
* **Инструмент автоматизации:** Selenium WebDriver
* **Архитектура:** Page Object Model (POM)

## 🧪 Что протестировано в проекте:

### 1. Выпадающий список в разделе «Вопросы о важном» (`test_main_page.py`):
* Проверка раскрытия всех элементов аккордеона.
* Валидация текста ответов на соответствие ожидаемым данным.

### 2. Весь путь оформления заказа (`test_order_page.py`):
* Переход к форме заказа через две разные точки (кнопка в хедере и кнопка внизу страницы).
* Заполнение всех полей формы заказа (Имя, Фамилия, Адрес, Станция метро, Телефон).
* Выбор даты, срока аренды, цвета самоката и добавление комментария.
* Проверка появления модального окна с подтверждением успешного создания заказа.

### 3. Навигация и логотипы:
* Переход на главную страницу «Самоката» при клике на логотип сервиса.
* Переход на главную страницу Дзена (yandex.ru) в новом окне при клике на логотип Яндекса.

## 📂 Структура проекта
* `locators/` — описание локаторов элементов для каждой страницы.
* `pages/` — методы взаимодействия со страницами (Page Object).
* `tests/` — тестовые сценарии.
* `conftest.py` — фикстуры для инициализации драйвера (Chrome/Firefox).

## 🚀 Как запустить
1. Установите зависимости: `pip install selenium pytest`
2. Запустите тесты: `pytest`
