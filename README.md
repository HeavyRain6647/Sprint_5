# Основы тестирования на Python (Sprint 5)

Практическая работа по использованию фреймворка Pytest и инструментов автоматизации.

### Ключевые темы:
* **Фикстуры (Fixtures):** Настройка окружения до и после тестов (setup/teardown).
* **Параметризация:** Запуск одного теста с разными наборами входных данных.
* **Unit-тестирование:** Проверка внутренней логики классов и методов.
